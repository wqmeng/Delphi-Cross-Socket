## 实施顺序

| 项目 | 内容 | 保留标准 |
|---|---|---|
| P0 | 冻结原算法与源码；建立跨编译器差分回归、分配计数和交替微基准；先运行基线与 A/A | 原算法逐输入输出及异常可比较，基准可复现 |
| P1 | 自动检测及标准编码单例使用固定 BOM 字节比较；默认编码延后获取 | 自定义/无 BOM 编码仍走 GetPreamble；三目标回归通过，短输入分配降低 |
| P2 | 标准 UTF-8 在 FPC 直接解码到结果，省重复计数、临时字符串和 Move | 保留底层宽容转换、终止符长度及异常；Delphi 路径不强行改写 |
| P3 | 自动探测复用 ASCII 识别，直接扩展写入结果 | 不增加非 ASCII 全量预扫描，不绕过自定义编码对象 |
| P4 | 探测 UTF-8 时合并计数，正常输入省独立计数；特殊输入原路处理 | 四字节字符计为两个 UTF-16 单元；旧式非法输入输出/异常保持一致；收益不足或回退则撤回该候选并记录 |

每项按“修改前源码快照 → 单项修改 → 三目标普通和 Checked 回归 → 独立前后性能对比 → 决定保留/撤回 → 更新本计划”执行。后项以已验收前项为基线。仅撤回本任务自己的候选，不触碰用户改动。

## 行为回归

- 冻结原 GetBufEncoding、IsUTF8、四种 GetString 重载及指针解码 helper，比较输出 UTF-16、异常类名和消息。
- ASCII（含 NUL）、中文、二/三/四字节 UTF-8、BOM/仅 BOM/部分 BOM、UTF-16LE/BE 奇偶长度、默认代码页回退、旧式 5/6 字节、过长、代理码点、越界码点及截断序列。
- nil/空/负 count 的既有短路行为，有效数组切片及非对齐指针；不刻意解引用非法地址。
- 标准编码、独立实例、关闭 BOM 的 Delphi 编码、自定义编码及覆盖转换方法的子类。
- 内存流和非内存流从不同 Position 读取的结果、异常和 Position 保持一致。
- 定向边界样本、所有 1/2 字节组合、确定性随机和合法 Unicode 样本。
