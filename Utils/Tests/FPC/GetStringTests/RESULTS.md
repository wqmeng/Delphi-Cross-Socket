## 每项取舍

1. **P1 / p1-fixed2**：无分配 BOM 比较，默认编码延后获取。无 BOM 输入少 3 次分配。标准单例之外仍调用 GetPreamble。最终补充嵌套长度保护，使 B+ 也不越界。
2. **P2 / p2**：FPC 标准 UTF-8 直接写结果，少一次临时字符串和复制；沿用 IgnoreInvalid=True 及终止符容量。Delphi 不强行替换 RTL。
3. **P3 / p3c**：ASCII 复用已知长度，经内联内部 helper 写入结果。放弃逐字节扩展首候选，其 Delphi 大文本曾回退约 12%–36%；也记录了抽取 helper 的约数 ns 固定成本。
4. **P4 / p4d**：探测同时计算正常 UTF-8 的 UTF-16 长度，特殊输入长度标记为 -1 回原 helper。有界 packed record 机器字扫描避免 ASCII 大文本回退。掩码各字节均为 80，与字节序无关。

P4 首候选使 Delphi ASCII 回退约 30%，未保留。Move 批量读取候选的反汇编显示每块调用 System.Move，也未保留。常量类型曾分别触发 Delphi Win32/FPC Checked 编译错误，最终用按位宽的显式 NativeUInt 常量，未关闭检查。

独立审查指出 BOM 复合条件依赖短路。保护页在旧候选 B+ 上复现 1 字节输入越界，最终拆成独立长度检查；三目标 B+ Checked 验证通过。最终只读复核未发现新增高置信正确性问题。

## 波动和边界

- 最终 A/A 选定样本多数在约 2% 内，Win32 默认编码回退样本出现 -7.9%，因此不把该样本的小差异当成收益。最终该样本 +0.2%，基本持平。
- FPC 自定义编码样本最终 +3.4%，150ms 独立复测 +2.2%（约 10ns）；分配不变，属于保留通用分派的成本，不宣称所有场景均变快。FPC 默认回退复测 -1.4%，同样没有明确吞吐收益。
- 首轮未固定 CPU 的 Win32 自定义样本曾 +69%，固定 CPU/相同测试构建复测未复现；FPC 大 ASCII 首轮曾 +33%，150ms 独立复测 +0.8%。这些原始结果保留在 bin，未当作可复现结论。
- P1 之后生产源码曾被回写为原始基线；来源未确定。保存了哈希/mtime，排除 p1-fixed（实际编译了基线）；之后显式从冻结快照构建。写回最终文件前确认当前仍完全等于基线，写回后重新构建和核对哈希。
